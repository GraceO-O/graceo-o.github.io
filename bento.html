Bento Box

This project is a responsive Bento Box style gallery that showcases my favorite foods using Bootstrap’s row and col grid system. Inspired by the structured layout of a Japanese lunchbox, the web page organizes different cuisines and dishes into an eye-catching, asymmetrical grid of varying card sizes.
